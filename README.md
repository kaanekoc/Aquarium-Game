# Aquarium Game

A 2D/3D Aquarium simulation game built with Unity. 

## Proje Hakkında
Bu proje, kullanıcıların kendi sanal akvaryumlarını yönetmelerini sağlayan eğlenceli ve dinlendirici bir simülasyon oyunudur.

## Teknolojiler
- **Oyun Motoru:** Unity 3D
- **Programlama Dili:** C#

## Kurulum
1. Bu depoyu bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/kaanekoc/Aquarium-Game.git
   ```
2. Unity Hub'ı açın ve `Add` butonuna tıklayarak projenin bulunduğu klasörü seçin.
3. Projeyi uygun Unity sürümü ile açın ve oynamaya başlayın!
