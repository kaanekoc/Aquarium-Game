## 🐠 Proje Hakkında
**Aquarium Game**, oyunculara kendi sanal akvaryumlarını kurma, yönetme ve izleme şansı sunan sakinleştirici bir oyun projesidir. Balıklarının etkileşimlerini izleyebilir, su altı ortamının tadını çıkarabilir ve arka plandaki ambiyans müzikleriyle rahatlayabilirsin!

✨ **Temel Özellikler:**
- 🐟 **Etkileşimli Balıklar:** Akvaryumunda yapay zeka destekli olarak gezen farklı balıklar.
- 🎨 **Canlı ve Akıcı Grafikler:** Unity URP (Universal Render Pipeline) ile desteklenmiş şık görseller.
- 🎵 **Rahatlatıcı Atmosfer:** Dinlendirici arka plan müzikleri ve su altı ambiyans ses efektleri.
- 🎮 **Kullanıcı Dostu Arayüz:** TextMeshPro ile güçlendirilmiş interaktif ve şık menü kontrolleri.

## 🚀 Kurulum & Çalıştırma

Bu projeyi kendi bilgisayarında denemek için aşağıdaki adımları izleyebilirsin:

1. **Projeyi Bilgisayarına İndir:**
   ```bash
   git clone https://github.com/kaanekoc/Aquarium-Game.git
   ```
2. **Unity Hub'ı Aç:** `Add` (Ekle) butonuna tıklayarak projenin bulunduğu klasörü seç.
3. **Sahneyi Yükle:** `Assets/Scenes` klasörü altındaki `StartScene` veya `SampleScene` sahnelerine çift tıklayarak oyunu açabilirsin.
4. **Oynamaya Başla:** Üstteki `Play` butonuna bas ve sanal akvaryumunun tadını çıkar!
